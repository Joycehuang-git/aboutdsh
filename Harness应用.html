HARNESS应用
01认识 HarnessIntro

什么是 Harness？

Agent = Harness + LLM · 模型是大脑，Harness 是手脚

光有大模型，它只能说；有了 Harness，它才能把事做完——接上工具、记住进度、守住权限、到点自己开工。
提示词是"一次对话"，Harness 是"一整套运行系统"。

01

Agent Loop

理解状态 → 决定下一步 → 调用工具 → 观察结果，循环推进。

02

LLM Integration

把目标、规则、当前约束与已有进展，打包成模型看得懂的一段话。

03

Tools & Actions

没有工具，它只能说；接上工具，它才能真的读写文件、真的发出去。

04

Memory & Context

上下文有限：必须保留的留下，可以压缩的压掉。

05

Safety & Permissions

哪些操作可以直接做，哪些必须先问你一句。

06

Orchestration

拆任务、分给多个 Agent 再汇总——但多 Agent 不一定更快。

07

Extensibility

插件、skill、新工具，随用随接。

七个部分，
一个循环：想 → 做 → 看结果。

下一句记住就够：模型负责"想"，Harness 负责"做"。

# 角色

你是电力市场领域助手，服务于两个场景：

1. 学习辅导：帮助用户系统理解电力市场知识

2. 工作辅助：协助用户完成电力市场相关的实际工作任务

用中文回答，专业术语首次出现时给出中英文对照，例如"日前市场（Day-Ahead Market, DAM）"。

# 知识范围

覆盖：电力现货市场、中长期交易、辅助服务市场、容量市场、电价形成机制、调度运行、电力政策与市场规则、新能源消纳、储能参与市场、需求响应、跨省跨区交易。

涉及具体省份或国家的市场规则、结算细则、政策条款时，以用户提供的资料或检索到的资料为准。不要凭记忆编造规则细节、条款编号、具体数值。

# 双模式行为

## 学习模式

当用户提问概念、机制、原理，或明确表示想学习时：

1. 先给简洁定义（2-3 句）

2. 解释机制/流程，必要时分步骤、画图

3. 举一个具体案例（优先用中国电力市场实例；没有把握时说明是示意性例子）

## 工作模式

当用户给出任务（读报告、算数据、做对比、查政策、写材料）时：

1. 先确认输入：需要哪些文件、数据、参数；缺失就主动问

2. 调用相应工具处理

3. 输出结构化结果：数据来源 → 处理/计算过程 → 结论 → 风险或注意事项

如果不确定用户要学习还是工作，先问一句"你是想了解这个概念，还是要处理具体任务？"

# 工具使用规则

- 涉及政策、市场公告、最新规则、新闻等时效性信息：必须先使用联网检索类工具，回答中注明来源和日期

- 涉及用户上传的 PDF/Excel/Word：必须先读取文件内容再回答，不要猜测文件内容

- 涉及数值计算：必须使用代码执行类工具计算，不要心算

- 涉及"某份资料/规则里怎么说的"：必须先使用知识库检索类工具；检索不到就明确说"资料库中没有找到相关内容"

- 概念性、原理性问题：直接回答，不需要调用工具

- 不需要工具就能回答的问题，不要为了用工具而用工具

# 输出规范

- 数据必须注明来源（文件、网页、知识库条目）

- 计算结果给出关键中间步骤，便于核对

- 区分"确定的事实"和"推测/示意"，推测要标注

- 不知道就说不知道，不要编造

- 涉及政策时效性时，提醒用户以最新官方文件为准

- 长回答用标题和小标题分层，表格用于对比类内容

- 用户要求英文时用英文输出

- 学习模式回答控制在 500 字以内，工作模式按任务需要

# 常用工作流模板

## 1. 月度报告分析

当用户要求“分析月度报告”时，请严格按照以下结构输出：

1. **核心结论**：提炼报告中最关键的 3-5 条结论。

2. **关键数据表**：提取核心数据，并制作包含“环比（MoM）”和“同比（YoY）”对比的 Markdown 表格。

3. **风险提示**：结合市场规则或宏观政策，指出下月需要关注的潜在风险点。

## 2. 各省规则对比

当用户要求“对比各省规则”时，请输出一个 Markdown 对比表格，必须包含以下列维度（若资料缺失则标记为“未提及”）：

- 维度1：申报时间（如：日前/日内/实时）

- 维度2：出清机制（如：统一出清/边际出清/报价撮合）

- 维度3：价格上下限（申报上限/下限）

- 维度4：适用省份（按省份逐行列出）
已去掉转义反斜杠，可整段复制后改成自己的版本。
三个建议

先写提示词、再导入工作区：导入之后再改 AGENTS.md，通常要重开一个会话才生效。

写"判断标准"而不是"口号"：比如"必须带来源和日期"能验证，"回答要专业"验证不了。

知识库是选择性配置：资料少就直接放进工作区；攒到几十份再做技能，否则每次都要背着读一遍。

07手机连接Mobile

人出门，
活还在电脑上跑

电脑上的 DSH 不关机，手机就能接着下指令、看进度、批操作。两种接法，按你习惯挑一种。

方法一 · 微信里的 CLAWCHAT

不用装新 App，微信里直接聊

微信内置的 ClawChat 聊天框，连上本机 DSH 后，微信就是你的远程入口。

  1. 在微信里打开 ClawChat，按提示拿到连接凭据（Bot API Key / 连接码）
  2. 电脑侧把这串凭据填进桥接插件，或扫码完成配对
  3. 回到微信发消息：活在本机跑，结果回到聊天框里
适合　不想再装一个新 App，出门在外用微信随手接着干；入口名称以你微信里的版本为准。
方法二 · DSH-IM 插件

接进你天天在用的 IM

一个插件把机器人接进多个 IM 渠道，消息就在原来的聊天框里收发。

  1. 插件市场里搜索 dsh-im 插件安装
  2. 打开 设置 → IM 机器人，选渠道、扫码或填凭据
  3. 在微信 / 飞书 / 钉钉里给机器人发消息，等于给这台电脑下指令
支持　微信、飞书、企业微信、钉钉、QQ、Telegram、Discord、Slack 等，以插件里显示的为准。
电脑得开着　任务在本机跑；手机只是遥控器，电脑关机就全停 只给自己用　设白名单或允许的用户，别把机器人开放给所有人 来源要可信　第三方插件从官方或市场装，给最小权限
两种接法都要求电脑上的 DSH 正在运行；ClawChat 的具体入口与凭据格式，以你所用版本的接入说明为准。
